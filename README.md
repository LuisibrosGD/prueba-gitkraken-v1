# Proyecto de Prueba para GitKraken

Proyecto para practicar el trabajo con ramas en Git usando GitKraken.

## 🎯 Objetivo

Aprender a crear, cambiar y fusionar ramas utilizando GitKraken.

## 🌿 Ramas del Proyecto

- **main**: Rama principal con la funcionalidad base
- **feature/mensaje-bienvenida**: Añade mensaje de bienvenida animado
- **feature/contador-clics**: Añade contador de clics interactivo
- **feature/theme-switcher**: Añade cambio entre tema oscuro/claro

## 🚀 Cómo usar

1. Clona el repositorio
2. Abre el proyecto en GitKraken
3. Cambia entre las diferentes ramas para ver las características
4. Practica haciendo merge de ramas
5. Resuelve conflictos (creados intencionalmente)

## 📝 Prácticas sugeridas

1. Crear una nueva rama desde main
2. Hacer commits en diferentes ramas
3. Fusionar una rama con main
4. Crear y resolver conflictos
5. Rebase de ramas
6. Stash de cambios

## 🎨 Personalización

Puedes modificar los archivos para crear tus propias características y practicar más.
